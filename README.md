# Парсер вакансий с HeadHunter

Этот проект представляет собой консольное приложение для поиска и фильтрации вакансий с сайта HeadHunter через его API. Проект включает в себя несколько модулей для работы с API, обработки данных, сохранения в JSON и взаимодействия с пользователем.

## Основные возможности

- Поиск вакансий по ключевому слову
- Фильтрация вакансий по зарплате (топ-N вакансий)
- Поиск вакансий по ключевому слову в описании
- Сохранение вакансий в JSON-файл
- Удаление вакансий из файла
- Получение информации о конкретной вакансии по ID

## Структура проекта

Проект состоит из следующих модулей:

1. **config.py** - содержит конфигурационные данные для API HeadHunter
2. **head_hunter_api.py** - класс для работы с API HeadHunter
3. **json_saver.py** - класс для сохранения вакансий в JSON-файл
4. **parser.py** - абстрактный базовый класс для парсеров
5. **saver.py** - абстрактный базовый класс для сохранения данных
6. **user_interaction.py** - класс для взаимодействия с пользователем
7. **vacancy.py** - класс для представления вакансии
8. **work_with_vacansies.py** - класс для работы с коллекцией вакансий
